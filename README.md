# Competitive Programming Solutions 🚀

Welcome to my Competitive Programming repository!

I maintain this repository to **safely back up and track all the problems I solve** across contests and practice sessions. *(I previously lost a large collection of my solutions due to a laptop issue, so this repo serves as both my permanent cloud backup and a quick revision log for algorithms and patterns.)*

---

## 🛠️ Environment & Setup
* **Language:** C++20 (`g++`)
* **Editor:** Visual Studio Code + Competitive Programming Helper (CPH)
* **Primary Platform:** Codeforces

---

## 📂 Structure
* Each file is named after the problem's division letter and title (e.g., `D_Good_Substrings.cpp`).
* Key logic notes and explanations are included directly inside the solution files as comments for fast contest revision.

---

## 🎯 Goals
* Back up solutions regularly after every contest and practice session.
* Build strong intuition across data structures, graphs, trees, dynamic programming, and strings.
